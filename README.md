# Personal Portfolio Website

Welcome to my personal portfolio website! This project serves as a central hub to showcase who I am, the projects I've worked on, and my journey as a Computer Science student, developer, and artist.

> **Status:** This website is currently under development. New features, projects, and improvements will be added over time.

## About

This portfolio is designed to highlight my skills, experiences, and personal projects. It includes information about my background, technical skills, and the work I enjoy creating—from web development and software engineering to game development and digital art.

## Running Locally

1. Clone the repository.

```bash
git clone https://github.com/Warrenym/My-Website
```

2. Open the project folder.

3. Launch `index.html` in your browser, or use a local development server such as VS Code Live Server.
